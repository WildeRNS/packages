# Очікуване добове споживання електроенергії будинком

![Home Assistant](https://img.shields.io/badge/Home%20Assistant-Packages-blue.svg)
![License](https://img.shields.io/badge/License-MIT-green.svg)

Ці сенсори розраховують **очікуване добове споживання електроенергії будинком** (кВт·год) на основі адаптивної моделі, що враховує прогноз СЕС, погоду та календарні фактори.

  ---

  ### 📐 Математична модель розрахунку:

  1. **Зважена база споживання (`blended_cons`):**
     * `50%` споживання за вчора + `50%` середнього споживання за останні 7 днів.
     * Це дозволяє системі швидко реагувати на зміну побутових звичок.

  2. **Базове (незалежне) навантаження (`base_load`):**
     * Розраховується як **мінімум за 7 днів** (або не менше $30\%$ від середнього).
     * Енергія, яку будинок споживає завжди (холодильники, септик, роутери, сервер, чергове освітлення).

  3. **Сонячно-залежна поведінка (`solar_factor`):**
     * Враховує, що у сонячні дні споживання зростає (автоматичний запуск бойлерів, зарядка АКБ, кондиціонери, прання).
     * $solar\_factor = \frac{blended\_cons - base\_load}{solar\_7d\_avg}$
     * Прогнозований приріст від СЕС = $s\_volcast \times solar\_factor$.

  4. **Температурна корекція (Комфортний діапазон: 22°C ... 24°C):**
     * ☀️ **Літо (> 24°C):** $+0.4\text{ кВт·год}$ на кожен $+1^\circ\text{C}$ (кондиціонування).
     * ❄️ **Зима (< 22°C):** $+0.5\text{ кВт·год}$ на кожен $-1^\circ\text{C}$ (додатковий обігрів).

  5. **Коригування на вихідний день:**
     * У вихідні дні (субота/неділя або свята) до загального прогнозу додається **$+12\%$** за допомогою `binary_sensor.workday_sensor`.

  6. **Захист від аномалій (Сатурація):**
     * **Нижня межа:** Прогноз не може бути меншим за `base_load`.
     * **Верхня межа:** Прогноз обмежений максимум $135\%$ від середньозваженого споживання.

  ---

  ### ⏰ Тригери оновлення:
  * **На завтра:** Перераховується щодня о **20:00**, при зміні прогнозу `Volcast Tomorrow`, при **старті Home Assistant** та при **перезавантаженні шаблонів**.
  * **На сьогодні:** Перераховується щодня о **06:00**, при зміні прогнозу `Volcast Today`, при **старті Home Assistant** та при **перезавантаженні шаблонів**.
