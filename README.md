# Home Assistant Packages Collection 🏡⚡

Збірка адаптивних конфігурацій (YAML Packages) для системи автоматизації **Home Assistant**, спрямована на інтелектуальне керування та прогнозування домашнього енергоспоживання.

---

## 📦 Склад репозиторію

### 1. ☀️ solar-battery-managment
Комплексний пакет налаштувань для інтелектуального керування гібридним сонячним інвертором (підтримка брендів *Anenji / PowMr / Voltronic*), акумуляторною батареєю (*LiFePO4 з BMS*) та зовнішнім DIN-реле введення мережі 220В.

* **Ключові можливості:**
  * **Оптимізація споживання:** Динамічне підлаштування роботи системи під графіки аварійних або планових відключень світла.
  * **Автоматичний резерв:** Розрахунок та підтримка необхідного залишку енергії в АКБ для критично важливих споживачів.
  * **Захист акумулятора:** Автоматичний захист комірок LiFePO4 від глибокого розряду.
  * **Розумний заряд:** Динамічне регулювання струму заряду залежно від поточної генерації сонячних панелей (СЕС) та доступності міської мережі.

### 2. 📉 house_energy_forecasting
Адаптивна математична модель для динамічного розрахунку очікуваного добового споживання електроенергії будинком у кВт·год.

* **Ключові можливості:**
  * **Адаптивна база (Blended base):** Розрахунок на основі 50% вчорашнього споживання та 50% середнього показника за останні 7 днів.
  * **Виявлення базового навантаження:** Автоматичне визначення мінімального постійного споживання будинку (`base_load`) за тиждень.
  * **Сонячно-залежний фактор:** Врахування підвищення внутрішнього споживання (бойлери, кондиціонери) у дні високої генерації СЕС на основі прогнозів.
  * **Температурна та календарна корекція:** Автоматичне коригування прогнозу при виході температури за межі 22°C...24°C та збільшення розрахунку на вихідні/святкові дні на +12%.
  * **Захист від аномалій:** Обмеження фінальних прогнозів верхніми та нижніми лімітами для уникнення помилок в автоматизаціях.

## 🛠️ Встановлення

1. Скопіюйте необхідну папку пакунка (`solar-battery-managment` або `house_energy_forecasting`) до вашого внутрішнього каталогу пакунків Home Assistant (зазвичай це папка `packages/` в директорії конфігурації).
2. Переконайтеся, що у вашому файлі `configuration.yaml` увімкнено підтримку пакунків:
   ```yaml
   homeassistant:
     packages: !include_dir_named packages
   ```
3. Перевірте конфігурацію та перезапустіть Home Assistant (або оновіть шаблони та автоматизації через Інструменти розробника).
